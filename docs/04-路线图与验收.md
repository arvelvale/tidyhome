# 路线图与验收

> 当前阶段：**阶段 0 · 可行性探针**（2026-10-24 启动）

## 阶段 0 · 可行性探针（关键路径）

目的：在产品负责人的真机上回答两个问题——
1. 桌面节点树里能不能找到每个图标（名字 + 位置）？
2. 能不能自动把两个图标合成一个文件夹？用语义动作还是手势？

交付：一个"探针"APK，界面上三个按钮：
- 「① 探测桌面」：自动回到桌面，导出完整节点树（含每个节点的可用动作）到文件，并在界面显示摘要
- 「② 语义建文件夹」：取当前页前两个应用图标，用"移动 → 创建文件夹"语义动作合并
- 「③ 手势建文件夹」：同样两个图标，用模拟拖动合并

验收：
- [x] 本机编译通过，APK 产物已校验（SHA256 90D12946…8DA2）
- [x] 产品负责人手机上 ① 能导出节点树：10 页 54 个应用 + 18 个文件夹（修正识别规则后）
- [x] 至少一种方式能建出文件夹：手势拖动（adb 实测），合成新文件夹、加入已有文件夹都成功；语义驱动不可用
- [x] 决定阶段 1 主驱动：手势驱动（ADR-013）
- [ ] App 内的手势探针 ③ 用实测参数在真机上复现成功（adb 注入和无障碍 dispatchGesture 可能有差异）

**阶段 0 结论（2026-10-24）：可行，进入阶段 1。**

**通过 → 阶段 1；①失败 → 重新评估方案（截图识别 / 自定义启动器）。**

## 阶段 1 · 执行引擎

- 多页扫描（翻页读取所有桌面页）
- Planner：按类别生成步骤（先用写死的测试分类）
- Executor：读 → 做 → 验循环，失败重试 1 次后跳过
- 音量键中止 + 顶部进度提示条
- 文件夹重命名

验收：20 个图标按写死的分类归成 4 个文件夹，全程无人干预；中途按音量键 1 秒内停止。

## 阶段 2 · 归类 + 预览

- 分类词典 `categories.json` + 关键词规则 + 系统 category 字段
- 预览页：分类结果、手动改类别、取消某一类
- 首次使用引导（权限、受限设置、整理前提醒截图）

验收：产品负责人的真实桌面分类结果他自己看着觉得对（"其他"占比 < 15%）；完整走一遍用户流程。

## 阶段 3 · 打磨与开源

- 完成页统计、异常文案温柔化
- README 截图/GIF、贡献指南（社区适配其他桌面）
- 发布 GitHub Release（APK）
