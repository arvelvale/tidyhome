# 真机测试指南

> 给想在自己手机上试这个 App 的人。目前只在一加 13 / Android 16 / ColorOS 桌面上验证过，其他桌面不保证可用。
> 现在还没有发布安装包，需要自己用 Android Studio 或 `./gradlew assembleDebug` 构建（见 README）。

## 一次性准备

### 1. 打开「USB 调试」（只有用电脑安装、看日志时才需要）
1. **设置 → 关于手机**，连续点 **版本号** 7 次，进入开发者模式
2. **设置 → 系统 → 开发者选项** → 打开 **USB 调试**
3. 用数据线连电脑，手机弹出"允许 USB 调试吗？"→ 允许
4. `adb install -r app-debug.apk`

### 2. 整理前先截图（重要）
App 会真的移动你桌面上的图标，而且**没有一键撤销**。先把每一页桌面都截个图，想复原时可以对照着拖回去。

### 3. 关掉会抢焦点的无障碍服务
实测谷歌「开关控制」（Switch Access）开着时，它的设置向导会弹到前台、打断手势。进入 **设置 → 无障碍**，把它关掉。App 在扫描前也会检测并提醒。

### 4. 开启「一键理桌」的无障碍权限
1. 打开 App，首页点 **去开启**，照页面上的四步走（设置 → 无障碍 → 已下载的应用 → 一键理桌 → 打开）
2. **如果开关是灰色、点不动**（Android 13 以后，对非应用商店安装的 App 会这样）：设置 → 应用 → 一键理桌 → 右上角 ⋮ → **允许受限设置**，再回去打开

## 整理流程

1. 点 **扫描桌面**：手机会切到桌面读一遍，再自己回到 App。只读，不会改动。
2. 在预览页检查分类。点任意应用可以换分类；某一类想保持原样可以点「这一类不动」。
3. 点 **开始整理**，确认三件事后开始。**整理时别碰屏幕**，顶部进度条会显示正在移动哪个应用。
4. 想停下就按**任意音量键**，它会立刻停手，桌面保持停下那一刻的样子。

首次打开 App 还有一段三步的聚焦式引导，最后一步会指出音量键的位置。

## 常见情况

| 现象 | 怎么办 |
|---|---|
| 扫描报"找不到桌面工作区" | 桌面上可能开着文件夹。App 会尝试按返回键关掉并重试；仍不行就手动回到桌面主页再扫一次 |
| 开着「开关控制」之类的服务 | 先关掉，再扫描 |
| 整理中途图标放错了位置 | 按音量键停下，手动拖回；欢迎带着日志提 issue |
| 新建的文件夹没有自动改名 | 改名流程在真机上还没完全验证，长按文件夹手动改名即可 |

## 开发者工具（仅 debug 构建）

debug 构建里，**长按首页左上角的小标题「一键理桌」**可以进入「开发者工具」页：导出桌面节点树、手势拖动测试、复制结果。正式构建里没有这个入口。

整理引擎每次运行会把完整日志写到 `Android/data/io.github.tidyhome/files/engine-last-run.txt`，提 issue 时请附上这个文件。
