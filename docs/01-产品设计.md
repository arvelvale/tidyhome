# 产品设计（PRD）

> 产品负责人：ArvelVale · 方案：Opus · 版本 v0.1（2026-10-24）
> 标 🔒 的条目是产品负责人已拍板的产品决策，改动前需要问他。

## 1. 要解决的问题

手机装的 App 越来越多，桌面越来越乱。整理只能靠手一个个长按拖动，几十个图标要拖十几分钟，
所以大多数人干脆不整理。厂商自带的"自动归类"要么没有，要么很粗糙。

## 2. 产品定位

- 🔒 **一次性大扫除**：桌面乱了，点一下，自动把图标按类别归进文件夹。不是常驻的智能桌面。
- 🔒 **安卓**。第一版先适配产品负责人手机上的 **ColorOS 桌面**（一加 13 / Android 16），再适配原生 AOSP / Pixel 桌面（见 ADR-008）。
- 🔒 **不用大模型**：归类靠本地词典和规则，完全离线。
- 🔒 **开源**（MIT 协议）。

## 3. 目标用户

- 第一用户：产品负责人本人（原生安卓）。
- 后续：用原生/类原生系统、桌面图标多、懒得手动整理的人。

## 4. 用户流程

```
打开 App
  → 首次：引导开启无障碍权限（含"受限设置"解锁说明）
  → 点「扫描桌面」
  → 预览页：看到"社交 6 个 / 购物 4 个 / 其他 3 个……"，可以把某个 App 改到别的类别，或不整理某一类
  → 点「开始整理」，提示"整理约需 X 分钟，期间请别碰屏幕，按音量键可随时停止"
  → 自动回到桌面，图标开始自己动；屏幕顶部有进度条"正在把 抖音 放进 影音（12/40）"
  → 完成：回到 App，显示"整理了 40 个图标，建了 7 个文件夹，跳过 2 个"
```

## 6. 产品负责人提出的想法：整理时玩小游戏

**结论：整理期间"玩"小游戏做不了，但可以"看"。**

原因：整理时，屏幕上必须显示桌面本身，我们是在桌面上替你操作图标。如果把游戏盖在上面：
- 游戏能接收你的点击 → 它也会挡住我们自己的"假手指"，整理就失败了；
- 游戏不接收点击 → 你就没法玩。

两者冲突，无解（详见决策记录 ADR-005）。

**替代方案（已纳入第一版）**：整理本身就是一场"表演"——图标自己飞进文件夹。
我们在屏幕顶部放一条进度提示，实时显示"正在把 抖音 放进 影音"，让等待变成看热闹。
原生桌面的语义驱动下每步不到 1 秒，40 个图标大约 1 分钟内完成，不太需要用游戏打发时间。

## 7. 界面设计

交互原型：`design/一键理桌原型-v1.html`（v1.1）。
- 🔒 视觉：白底为主，**主色钴蓝**（产品负责人 2026-10-24 选定，见 ADR-009）；每个分类有专属浅色，预览页、完成页和桌面文件夹统一使用
- 首次打开有三步聚焦式引导：开权限 → 先扫描 → 音量键可停（最后一步指向机身侧面的音量键）
- 权限页照产品负责人真机（ColorOS）的路径画了一张迷你设置页，标出最难找的「已下载的应用」
- 字体：标题 Noto Serif SC，正文系统黑体；图标 lucide；文案中文、温柔

## 8. 成功标准

- 产品负责人的手机上：40 个左右的图标，整理成功率 ≥ 95%，全程无需手动干预。
- 整理中途按音量键能在 1 秒内停下，桌面不会出现图标丢失（停在拖动中途的图标会被桌面放回原处）。
